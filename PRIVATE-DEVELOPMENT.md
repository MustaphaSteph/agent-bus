This repository preserves the full development history and hosted application.
Keep this GitHub repository private. Do not publish its source, documentation,
design assets, or npm package without explicit owner approval.

The public Local distribution is maintained in the separate `agent-bus` GitHub
repository. Its checkout is `/Users/air/Documents/Projects/agent-bus-local`.
This checkout intentionally retains its existing path to avoid disrupting local
development servers, agent sessions, and deployment scripts.

`apps/cloud` remain separate from npm publication. Repository separation does
not change production resources, credentials, user data, or client connections.

The historical repository was previously public. Moving it here does not recall
existing forks, clones, npm releases, or copies. Do not claim otherwise.
